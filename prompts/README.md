# พรอมป์ต์และชุดข้อความสำหรับมินิไซต์ (minisite-v1)

โฟลเดอร์นี้รวบรวมข้อความและพรอมป์ต์ที่ใช้เฉพาะสำหรับ **มินิไซต์ (Minisite)** และ **อินโฟกราฟิกผู้สมัครรายบุคคล** เพื่อแยกออกจากงานโปสเตอร์หลักที่โฟลเดอร์ภายนอก

## รายการไฟล์ในโฟลเดอร์นี้

1. **`ข้อความอินโฟกราฟิก-รายผู้สมัคร.txt`**:
   - ข้อความที่ผ่านการตรวจสอบและอนุมัติแล้ว สำหรับผู้สมัครทั้ง 3 ท่าน (หมายเลข 2, 3, 4)
   - ใช้เป็น Single Source of Truth สำหรับ `build.py` และการสร้างสื่อของแต่ละท่าน
   - ได้รับข้อมูลจริงของ ผศ.น.สพ.ดร.ธวัชชัย ศักดิ์ภู่อร่าม จาก `ธวัชชัยQR-data.pdf` ครบถ้วนแล้ว

2. **`infographic-หมายเลข2-ทวีวัฒน์.txt`**:
   - พรอมป์ต์ ImageGen สำหรับสร้างภาพอินโฟกราฟิกของ ผศ.ดร.ทวีวัฒน์ ทัศนวัฒน์ (หมายเลข 2)

3. **`infographic-หมายเลข3-ธวัชชัย.txt`**:
   - พรอมป์ต์ ImageGen สำหรับสร้างภาพอินโฟกราฟิกของ ผศ.น.สพ.ดร.ธวัชชัย ศักดิ์ภู่อร่าม (หมายเลข 3)
   - ใช้ข้อมูลจริงจากการศึกษา (ม.เกษตรศาสตร์ / ม.อะซาบุ ญี่ปุ่น) และนโยบายจริง

4. **`infographic-หมายเลข4-รังสรรค์.txt`**:
   - พรอมป์ต์ ImageGen สำหรับสร้างภาพอินโฟกราฟิกของ ผศ.ดร.รังสรรค์ ปีติปัญญา (หมายเลข 4)
   - ปฏิบัติตามกฎห้ามใช้คำว่า "ลดหนี้" โดด ๆ

## การนำไปใช้งาน

- เว็บไซต์มินิไซต์ถูกสร้างด้วยคำสั่ง:
  ```bash
  python3 build.py
  ```
  ในโฟลเดอร์ `minisite-v1/`
- ตรวจสอบความถูกต้องของลิงก์และคำสะกดด้วยคำสั่ง:
  ```bash
  python3 check.py
  ```
